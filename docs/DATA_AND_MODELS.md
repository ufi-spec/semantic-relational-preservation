# Data and models

This repository does not redistribute raw benchmark text or pretrained model weights.

## Multi-News

The experiment uses the Multi-News split and identifiers recorded by the released workflows. Users should obtain the dataset from the original public provider referenced in the notebooks/manuscript.

## WebNLG

WebNLG is used as an external gold-triple verification source. The public repository releases regrouping statistics and configuration, not a redistributed copy of the benchmark.

## Models

The robustness workflows reference their public model identifiers and, where recorded, model commits. Model weights are downloaded from their original providers.

## Public outputs

To reduce redistribution and privacy/licensing risk, public CSVs omit raw source text, full generated benchmark-derived summaries, and extracted text-bearing triple strings. They retain cluster identifiers, word-budget metadata, model identifiers/commits, preservation metrics, paired statistics, and aggregate results needed to audit the reported conclusions.
